# File icons

Language icons come from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme),
revision `13025adc5ad10a5cc649528a2c1edec93069f1b9`, under the included [MIT license](LICENSE.txt).

These transparent 64 × 64 PNGs were exported from the matching `icons/<name>.svg` files
using librsvg, without changing their artwork. Sylph displays them at 16 × 16 logical pixels
and shares the decoded images across file tabs and explorer rows. No runtime download is needed.

`react` represents JSX, `react_ts` represents TSX, and `console` represents shell scripts.
Unknown file types and folders use Sylph's theme-aware vector symbols.
